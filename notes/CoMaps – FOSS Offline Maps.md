# [CoMaps – FOSS Offline Maps](https://www.comaps.app/)

## Digest Summary
CoMaps provides offline navigation for hiking, biking, and driving, allowing users to plan and follow routes using only GPS without mobile data. The app supports waypoint searches on remote trails and paths, emphasizing privacy by not collecting user data. Additional features include battery conservation during use and a free, community‑developed model. Images associated with the content reinforce these points: offline search capability, privacy focus, battery‑saving benefits, and the open‑source nature of the tool.
