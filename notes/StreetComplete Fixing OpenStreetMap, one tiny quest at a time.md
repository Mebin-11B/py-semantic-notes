# [StreetComplete: Fixing OpenStreetMap, one tiny quest at a time](https://streetcomplete.app/)

## Digest Summary
StreetComplete is an OpenStreetMap surveyor app that identifies missing map data near the user and presents it as location‑based “quests.” Users visit each site, answer a brief question, and the entered information is immediately added to the map under their name, eliminating the need for a separate editor. The app is multilingual, supporting a wide range of languages, and is distributed via Google Play, F‑Droid, and its GitHub repository. Community resources include a Slack channel and several funding avenues such as Liberapay, GitHub Sponsors, and Patreon. StreetComplete aims to streamline crowdsourced map improvements by simplifying data collection and contribution workflows.

# StreetComplete


		

OpenStreetMap surveyor app
		
			
		
			
	
	
		
			
				
			
			
				
									
				
			

			
				
			
		
		
Help improve [OpenStreetMap](https://osm.org) with StreetComplete!This app finds missing map data in your vicinity and displays it on a map as quests. Solve each quest by visiting the location on-site and answering a simple question to update the map.The info you enter is directly added to [OpenStreetMap](https://osm.org) in your name, without the need to use another editor.
