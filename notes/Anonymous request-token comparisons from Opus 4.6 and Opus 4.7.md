# [Anonymous request-token comparisons from Opus 4.6 and Opus 4.7](https://tokens.billchambers.me/leaderboard)

## Digest Summary
The page hosts an open‑source “Tokenomics – Anthropic Token Cost Calculator” that aggregates community‑submitted data on token usage for Anthropic’s Opus models. It presents anonymous request‑token comparisons, highlighting performance differences between Opus 4.6 and Opus 4.7 on real‑world inputs. The dataset consists of stored rows identified only by anonymous submission IDs, ensuring no personal attribution. The tool is not affiliated with or endorsed by Anthropic.

## Discussion Summary
Comments focus on the sharp rise in token consumption and cost after the Opus 4.7 update, with many users noting faster exhaustion of limits and opaque pricing despite modest or uneven quality gains. Opinions are split: some perceive modest improvements in reasoning and conciseness, while others see no benefit or a regression toward over‑prompting and lower accuracy. Users frequently compare 4.7 to 4.6/4.5, favoring older versions for efficiency, and express frustration over limited transparency, tokenizer changes, and a shift toward higher‑priced, less‑value‑for‑money usage, prompting interest in alternative or open‑source models.
