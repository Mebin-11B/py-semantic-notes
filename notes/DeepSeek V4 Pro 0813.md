### How much does DeepSeek V4 Pro 0813 cost?

DeepSeek V4 Pro 0813 costs $1.115/M input tokens and $3.346/M output tokens, with separate rates for Cache Read at $0.03718/M tokens.

### What is the context length of DeepSeek V4 Pro 0813?

DeepSeek V4 Pro 0813 has a 1,048,576 token context window. It supports up to 384,000 completion tokens.

### Does DeepSeek V4 Pro 0813 support tool calling and structured outputs?

Yes. DeepSeek V4 Pro 0813 accepts  `tools`  and  `tool_choice`  for function calling. It supports  `response_format`  for JSON output, without JSON-schema enforcement.
