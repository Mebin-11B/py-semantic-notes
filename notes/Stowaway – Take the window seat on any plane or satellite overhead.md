# [Stowaway – Take the window seat on any plane or satellite overhead](https://stowaway.live/)

## Digest Summary
Stowaway is an interactive web application that lets users select any aircraft or satellite currently passing over their location and view a simulated window‑seat perspective. The view reflects real‑time conditions—including local weather, lighting, and terrain—by rendering the aircraft’s or satellite’s position over actual ground data. The site relies on JavaScript and WebGL 2 to generate the live graphics; enabling JavaScript activates the experience. Users click a vehicle on a map, after which the camera follows that object, creating a “stow‑away” seat view that updates as the craft moves. An example image shows a sunset view from a passenger window at cruise altitude, displaying Mount Rainier, scattered cumulus clouds over the Cascades, and a labeled airliner contrail. The tool emphasizes real‑time, geospatial visualization rather than static imagery.
