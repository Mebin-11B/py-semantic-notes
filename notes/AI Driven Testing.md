## One primitive, three modes.

Everything in Deltix is built on a single thing: an AI agent attempting a user task. The three modes are the three ways you run it.TaskTry once“Can my user actually do this?”

Ad-hoc. You’re building a new flow and you want to know if it works for a real user, without scheduling a research session. Write the task, watch the agent try, read the screenshot of where it got stuck.PlaybookSave and replay“Did we break it?”

Take any successful run and save it as a Playbook. Replay it deterministically on every build, from the dashboard. Pass or fail in seconds.ExperimentCompare two builds“Which design wins?”

Run the same task against two builds of your app, side by side. See which one your users can complete and which one breaks, before the design debate goes to A/B testing in production.How it fits
